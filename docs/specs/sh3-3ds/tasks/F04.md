# F04: tickets detallados

Estado y avance: [backlog principal](../tasks.md). Estos tickets describen trabajo; no acreditan ejecución.

Cada instancia se limita a un formato, recurso, estado, escena o perfil cuando corresponda. Objetivo de tamaño: 2-4 horas; un hallazgo inconcluso abre una instancia adicional sin cerrar el sistema.

**Requisitos:** RNF05.01, RNF04.02. Aplican además RNF07.06-RNF07.09 y RNF11.05-RNF11.09 cuando haya código.

**Pasos de ejecución:**

1. Fijar pareja Ghidra/EE.
2. Cargar ejecutable identificado.
3. Contrastar una observación en PCSX2.
